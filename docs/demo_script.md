# 演示视频分镜脚本（3~5 分钟）

> 录制工具：OBS Studio 或 Windows 自带录屏（Win+G）。
> 建议 1080p，出镜或旁白解说，展示完整功能流程。

## 一、开场（0:00~0:20）

- 画面：项目标题「Cyber Foodie Agent」+ 一句话介绍。
- 旁白：这是我们的 AI 大厨辩论系统——输入口味、预算和天气，两位 AI 大厨自动辩论，给你一顿好吃的建议。

## 二、启动系统（0:20~0:50）

- 画面：终端执行 `docker compose up --build`，后端 `/health` 返回 200，前端 Streamlit 打开。
- 旁白：系统采用 FastAPI + SQLite + Streamlit，Docker 一键启动，默认 Mock LLM 无需 API Key。

## 三、核心流程：启动辩论（0:50~1:40）

- 画面：选择「口味=辣、预算=中、天气=晴」，点击「开始辩论」。
- 旁白：系统触发川辣派与粤式养生派两位大厨，进行 3 轮自动辩论。
- 画面：展示聊天式发言记录，标注每轮发言的大厨身份。

## 四、战报展示（1:40~2:10）

- 画面：辩论结束后展示战报卡片：最终推荐、评分、获胜方、双方观点。
- 旁白：辩论结束后系统自动生成结构化战报，包含推荐菜品、理由、正反观点与评分。

## 五、自定义 Agent（2:10~2:50）

- 画面：进入「Agent 管理」页，克隆预设「川辣派」，修改提示词为「重辣版」，创建新 Agent。
- 旁白：用户可以创建或克隆自己的大厨，自定义性格提示词。
- 画面：回到辩论页，在下拉框选择自定义 Agent 参与辩论。

## 六、菜单导入与推荐（2:50~3:40）

- 画面：进入「菜单管理」页，上传 `eval/sample_menu.json`（21 道菜）。
- 旁白：用户导入食堂/外卖真实菜单，包含价格与口味标签。
- 画面：再次辩论，战报的 final_choice 来自菜单，显示菜品价格。

## 七、收尾（3:40~4:00）

- 画面：展示项目 GitHub 仓库（CI 绿灯、测试覆盖率、文档）。
- 旁白：项目经过 4 个 Sprint 迭代，具备完整 CI/CD、数据库迁移、评测体系。谢谢观看。

## 录制要点

- 每个功能点停留 3~5 秒，别快进。
- 旁白语速适中，可用手机/麦克风录音后合成。
- 上传 YouTube（不公开）或放 `docs/demo.mp4`（≤100MB 用 Git LFS）。
- 录完后把链接替换到 README 的「演示视频」处。
